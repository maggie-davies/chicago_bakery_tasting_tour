# Assignment4_chicago_bakery_trail
Updated: An updated map and dataset for Assignment 4 of NYU Wagner's Spring 2026 Advanced GIS/Web-Mapping course.

With this update, I honed my bakery list to my top 13 recommendations, added photos, website links, hours, and recommended items to try for all the bakeries, and essentially created the csv file to support different visualizations with the data on the map. I then converted the csv to a geojson using geojson.io

From there, I set up markers on the map using the vintage "marker" formatting that I loved from Assignment 3, and established popup windows to open when the use clicks on a marker, to share more information. This includes the name of the restaurant, a short blurb about it, the items I recommend to try there based on my research, the hours, and website.

I also used the Copilot feature of Visual Studio to help me create colored pills at the bottom of each popup that correspond with the seven categories in the baking competition. This can help my brother, the end user, organize his research depending on the categories he most wants to study. 

I slightly adjusted the map's starting point and zoom level to better center on the points illustrated, as well as including Evanston, IL, where my brother lives, so he can visualize his journey. 

Finally, I adjusted the spacing on the title box to add more space between the header, paragraph, and call to action lines.

The end product is a map with my thirteen most recommended bakeries, with additional information and features included upon clicking on the markers.

# Assignment3_chicago_bakery_trail

For this assignment, I researched and mapped acclaimed Chicago bakeries to create a tasting trail to recommend to my brother, who will be entering a baking competition there later this year. While it is an amateur baking competition, the stakes are rather high, as he has challenged himself with creating dishes in five separate baked goods categories. I created this list to help him gather ideas and enjoy tasting what Chicago has to offer along the way!

While I only included my top ten locations on this map, I have a longer list of 22 locations that I may build out in the future. I'd also like to include more details, images, and interactivity in my pop-ups, including a website link and recommended dishes to try.
